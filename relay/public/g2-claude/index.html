Claude Code, on your glasses

Follow a Claude Code session on Even Realities G2: see what it is doing, speak a prompt, approve a tool, answer a question, or stop it, without looking at a screen.

  • Watch

    Prompts, tool calls and Claude's replies scroll by as one timeline.

  • Speak

    Talk to start a turn. You see the words as you say them and confirm before anything is sent.

  • Approve

    Permission prompts and Claude's questions appear as cards you answer with a tap.

  • Stop and switch

    Halt Claude at the next tool call, and move between sessions from the side menu.

How it connects

Nothing on your computer listens to the internet. Claude Code starts a small channel next to each session, and that channel makes one outgoing, end-to-end encrypted connection to a relay on this site. The relay only ever passes ciphertext between your computer and the glasses app.

Claude Code session ── hooks + MCP ──▶ g2 channel (on your computer) │ encrypted ▼ relay at atillasaadat.com/g2-claude ▲ encrypted │ glasses app in the Even app ── Bluetooth ──▶ G2

Your Claude account never leaves Claude Code: everything goes through Claude Code's own channels, hooks and MCP tools. Remote Control on your phone keeps working at the same time.

Set it up

You need Claude Code signed in with a Claude account and Bun on your computer, Even Realities G2 with the Even app on your phone, and optionally a free Groq API key for voice.

  1. Install the Claude Code plugin

    In Claude Code, add this marketplace and install the plugin. It brings the channel and the hooks it needs, for every project.

    /plugin marketplace add atillasaadat/g2_claude_rc
/plugin install g2@g2cc

    The plugin installs from the public repository, github.com/atillasaadat/g2_claude_rc, where you can read every line it runs.

  2. Add the launch command

    Put this in ~/.zshrc or ~/.bashrc, then open a new terminal.

    alias cc-g2='claude --dangerously-load-development-channels plugin:g2@g2cc --rc'

    The flag loads the channel, which is a Claude Code research preview. The first launch shows a warning; choose that you are using it for local development. --rc also turns on Remote Control.

  3. Install the glasses app

    In the Even app, open Even Hub and install G2 Claude Code.

  4. Pair

    Start a session with cc-g2 and run /g2:pair. It shows a code like K7PM-4QXD. Open G2 Claude Code on your phone, type the code under Pairing, and tap Pair. A code works once and expires after 10 minutes, and it never contains your key: the two sides use it to agree on the key through an encrypted exchange.

    /g2:pair

    For voice, paste your Groq key in the app under Voice. It is stored on your phone only.

  5. Use it

    In any project, run cc-g2 instead of claude. The glasses show the session within a second. Start more sessions the same way; once there are two, the glasses' side menu lists them so you can switch.

  6. Get alerts when you are in another app

    The glasses app can only draw while it is open. For everything else, Claude Code's own phone notifications do the job, and the Even app mirrors them to your glasses.

    In a session, run /config and turn on the two Remote Control push settings: inputNeededNotifEnabled (a prompt or question is waiting) and agentPushNotifEnabled (Claude finished). Allow notifications for the Claude app on your phone, then allow the Claude app in the Even app's notification settings.

Using it

GestureWhat it does
Swipe up or downScroll the timeline three lines. The R1 ring works the same way.
TapOpen the menu: Talk, Stop Claude, End session. End session unpairs this phone after you confirm; run /g2:pair to reconnect. On a card, confirm the highlighted choice.
Double tapJump back to the newest line. On a card, leave it for later.
Side menuSwitch between sessions, clear ones you no longer use, or exit the app.

While you talk, a few words act straight away instead of being sent: stop halts Claude, cancel drops the recording, and approve or deny answer an approval card that is showing. Approval cards start on Deny, so a stray tap never approves anything. Gestures can be remapped in the phone view of the app.

If something is off

The glasses say waiting for Claude Code
Start the session with cc-g2, not claude. Its startup banner should mention plugin:g2@g2cc. Run /mcp to check that the g2 server is connected.
The pairing code is not accepted
Codes work once and expire after 10 minutes, and only while the session that made them is open. If the phone keeps looking for your computer, update the plugin (/plugin marketplace update g2cc, then restart the session) and run /g2:pair again.
Claude Code says the g2 server failed, or that it needs Bun
The plugin runs on Bun. Run /g2:setup and Claude installs it with the official installer, or install it yourself. Then open a new terminal and start the session again.
No approval cards appear
In auto mode Claude Code decides permissions itself, so there is nothing to approve. Press Shift+Tab in the session to change the permission mode.
Talk says no Groq key
Paste your key in the app under Voice.
Stop does not seem to do anything
Stop takes effect at Claude's next tool call. If Claude is only writing its answer, the turn ends normally.

Built by Atilla Saadat with Claude Code. Messages are encrypted end to end with AES-256-GCM using a key that only your computer and your phone hold; the relay forwards ciphertext and keeps a short buffer so the glasses can catch up after reconnecting.

To update the plugin, run /plugin marketplace update g2cc, or turn on auto-update for the g2cc marketplace under /plugin. New sessions use the update.
