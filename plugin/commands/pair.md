Call the g2 `pair` tool (no arguments). It shows the user a one-time code in a Claude Code dialog; the code never appears in this conversation, so do not ask the user for it. When the tool returns, tell the user its result in one line.

If the tool says the session cannot show a dialog, tell the user to run `/g2:pair` in an interactive `cc-g2` session.
